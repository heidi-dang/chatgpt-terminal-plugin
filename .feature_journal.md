# Feature Journal — Direct ChatGPT Terminal Expansion

## Architecture Context

This is an MCP (Model Context Protocol) terminal bridge that:
- Runs a public MCP server with OAuth authentication
- Connects to local agents via authenticated WebSocket
- Creates persistent PTY sessions via node-pty
- Renders a live xterm.js terminal in an MCP App iframe
- ChatGPT acts as the actor (writes commands, reads output)
- The terminal UI is watch-only (no keyboard input)
